    Difference Between map() and flatMap()

    map()

    [1, 2, 3].map(x => [x, x * 2]);

// Output:
// [
//   [1, 2],
//   [2, 4],
//   [3, 6]
// ]

    flatMap()

    [1, 2, 3].flatMap(x => [x, x * 2]);

// Output:
// [1, 2, 2, 4, 3, 6]

    Interview Point

    flatMap() = map() + flat(1)
    • map() transforms each item and returns an array.
    • flatMap() transforms each item and flattens the result by one level.
    • Use flatMap() when map() returns nested arrays and you need a single array.

    sort() Examples

    Numbers - Ascending

    (a, b) => a - b
    Result Action
    +ve Swap
    -ve Stay
    0 Stay

    Example:

    30 - 10 = 20

    ➡️ +ve

    Swap

    [30, 10]

    becomes

    [10, 30]

    Example:

    10 - 20 = -10

    ➡️ -ve

    Stay

    [10, 20]

    remains

    [10, 20]

    Numbers - Descending

    (a, b) => b - a
    Result Action
    +ve Stay
    -ve Swap
    0 Stay

    Example:

    20 - 50 = -30

    ➡️ -ve

    Swap

    [20, 50]

    becomes

    [50, 20]

    Example:

    50 - 20 = 30

    ➡️ +ve

    Stay

    [50, 20]

    remains

    [50, 20]

    Interview Cheat Sheet

    Ascending

    (a, b) => a - b

    +ve => Swap
-ve => Stay
0 => Stay

    Descending

    (a, b) => b - a

    +ve => Stay
-ve => Swap
0 => Stay

    a - b => Ascending
b - a => Descending

    Strings - Ascending (A → Z)

    a.localeCompare(b)
    Result Action
    +ve Swap
    -ve Stay
    0 Stay

    Example:

    'Raj'.localeCompare('Anil')

    Result:

    +1

    ➡️ Swap

    ['Raj', 'Anil']

    becomes

    ['Anil', 'Raj']

    Example:

    'Anil'.localeCompare('Raj')

    Result:

    -1

    ➡️ Stay

    ['Anil', 'Raj']

    remains

    ['Anil', 'Raj']

    Strings - Descending (Z → A)

    b.localeCompare(a)
    Result Action
    +ve Stay
    -ve Swap
    0 Stay

    Example:

    b = 'Raj'
a = 'Anil'

'Raj'.localeCompare('Anil')

    Result:

    +1

    ➡️ Stay

    ['Raj', 'Anil']

    remains

    ['Raj', 'Anil']

    Example:

    b = 'Anil'
a = 'Raj'

'Anil'.localeCompare('Raj')

    Result:

    -1

    ➡️ Swap

    ['Anil', 'Raj']

    becomes

    ['Raj', 'Anil']

    Full Cheat Sheet

    Numbers

    a - b // Ascending

    +ve => Swap
-ve => Stay
0 => Stay

    b - a // Descending

    +ve => Stay
-ve => Swap
0 => Stay

    Strings

    a.localeCompare(b) // A → Z

    +ve => Swap
-ve => Stay
0 => Stay

    b.localeCompare(a) // Z → A

    +ve => Stay
-ve => Swap
0 => Stay

    Remember

    Numbers => use -
Strings => use localeCompare()

    numbers.sort((a, b) => a - b);
numbers.sort((a, b) => b - a);

names.sort((a, b) => a.localeCompare(b));
names.sort((a, b) => b.localeCompare(a));

    Difference Between slice() and splice()

    Method Original Array Changes?
    slice() ❌ No
    splice() ✅ Yes

    slice()

    Used to take/copy items from an array.

    Original array stays unchanged.

    Example

    let numbers = [10, 20, 30, 40, 50];

let res = numbers.slice(1, 4);

console.log(res);

    Output:

    [20, 30, 40]

    How?

    Indexes:

    0 -> 10
1 -> 20
2 -> 30
3 -> 40
4 -> 50

    slice(1, 4)

    Take:

    1 -> 20 ✅
2 -> 30 ✅
3 -> 40 ✅
4 -> stop ❌

    Result:

    [20, 30, 40]

    Original array:

    console.log(numbers);

    Output:

    [10, 20, 30, 40, 50]

    Still unchanged.

    splice()

    Used to remove, add, or replace items.

    Original array gets modified.

    Remove One Item

    let numbers = [10, 20, 30, 40];

numbers.splice(1, 1);

console.log(numbers);

    Output:

    [10, 30, 40]

    How?

    splice(startIndex, deleteCount)

    splice(1, 1)

    Means:

    Start at index 1
Delete 1 item

    Remove:

    20

    Result:

    [10, 30, 40]

    Remove Two Items

    let numbers = [10, 20, 30, 40, 50];

numbers.splice(1, 2);

console.log(numbers);

    Output:

    [10, 40, 50]

    Removed:

    20
30

    Add Item

    let numbers = [10, 20, 40];

numbers.splice(2, 0, 30);

console.log(numbers);

    Output:

    [10, 20, 30, 40]

    How?

    splice(2, 0, 30)

    Means:

    Go to index 2
Delete 0 items
Insert 30

    Replace Item

    let numbers = [10, 20, 30];

numbers.splice(1, 1, 25);

console.log(numbers);

    Output:

    [10, 25, 30]

    How?

    splice(1, 1, 25)

    Means:

    Go to index 1
Delete 1 item
Insert 25

    Replace:

    20 -> 25

    Easy Memory Trick

    slice

    slice = copy

    let res = arr.slice(1, 3);

    Original array:

    Not changed

    splice

    splice = modify

    arr.splice(...)

    Original array:

    Changed

    Real Angular Example

    Remove patient with index 2:

    this.patients.splice(2, 1);

    Add new row:

    this.patients.splice(0, 0, newPatient);

    Replace a row:

    this.patients.splice(index, 1, updatedPatient);

    One-line Interview Answer

    slice() → returns a portion of an array without modifying the original array.

    splice() → adds, removes, or replaces items and modifies the original array.
