    Formatting & Editing

    29. Alt+Shift+F – Format the entire document
30. Ctrl+Shift+K – Delete current line
31. Ctrl+Enter – Insert line below without moving cursor
32. Ctrl+Shift+Enter – Insert line above
33. Ctrl+D – Select next instance of the same word (multi-cursor editing)
34. Ctrl+Alt+Down or Ctrl+Alt+Up – Add multiple cursors
35. Ctrl+Shift+L – Select all occurrences of current word
36. F2 – Rename symbol (like variable, method, class, etc.)

    📦 Terminal Efficiency

    37. Ctrl+` – Toggle terminal
38. Ctrl+C – Stop the current terminal command (e.g., ng serve)
39. Ctrl+Shift+5 – Split terminal pane
40. Ctrl+Tab (in terminal) – Switch between multiple terminal instances

    📁 Project & Folder Navigation

    41. Ctrl+B – Toggle sidebar visibility
42. Ctrl+Shift+E – Focus Explorer view
43. Ctrl+K Ctrl+0 – Fold all code regions
44. Ctrl+K Ctrl+J – Unfold all code regions
45. Ctrl+Space – Trigger suggestion/autocomplete manually
