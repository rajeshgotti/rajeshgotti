    How to use Store

    npm install @ngxs/store 

step:1 create one folder with any name and create one ActionClass AND state class 

    == SetActionData.ts== 
      export class SetActionData { 
         static readonly type = '[SetActionData] SetActionData'; 
         constructor(public payload: any) {}
      }

   ==state.ts== 
 import { State, Selector, Action, StateContext } from '@ngxs/store'; 
 import { SetActionData } from './empAction';

 export interface EmpStateModel {    //creating interface
      empEditData: any;
      firstName: string; 
  }

// here we will set default values with null
 @State<EmpStateModel>({ 
 name: 'SetActionData', 
 defaults: { 
          empEditData: null, 
          firstName:null,
          }, 
      })

// THIS IS THE CLASS 
 export class EmpStateClass { 
    @Selector() static getEmpEditData(state: EmpStateModel) { 
             return state.empEditData; 
           }

 @Action(SetActionData) 
 SetActionData(ctx: StateContext<EmpStateModel>, action: SetActionData){
   ctx.patchState({ empEditData: action.payload }); 
  } 
 }

 step:2 open app.config.ts import importProvidersFrom in providers

       providers: [ importProvidersFrom( NgxsModule.forRoot([ EmpStateClass ])) ]

    Ngrx operators

    1. filter – Allow Only Values That Meet a Condition

import { CommonModule } from '@angular/common';
import { Component, OnInit } from '@angular/core';
import { of } from 'rxjs';
import { filter } from 'rxjs/operators';

@Component({
  selector: 'app-demo',
  standalone: true,
  imports: [CommonModule],
  templateUrl: './demo.component.html',
  styleUrls: ['./demo.component.scss']
})
export class DemoComponent implements OnInit {
  myData: number[] = [];

  ngOnInit(): void {
    of(1, 2, 3, 4, 5).pipe(
      filter(x => x % 2 === 0)
    ).subscribe(res => {
      this.myData.push(res); //outPut: 2 4
    });
  }
}

----------Take------
2. take – Limit to First N Values
The take operator emits only the first N values, then completes.
import { interval } from 'rxjs';
import { take } from 'rxjs/operators';

interval(1000).pipe(
  take(3)
).subscribe(console.log); //output: 0 1 2

-------First-----
3. first – Emit Only the First Value (Optionally Matching a Condition)
The first operator emits only the first value from the stream and completes.

import { of } from 'rxjs';
import { first } from 'rxjs/operators';

of(1, 3, 7, 9).pipe(
  first(x => x > 5)
).subscribe(console.log);// Output: 7
---------Last-------
4. last – Emit Only the Last Value (Optionally Matching a Condition)
The last operator waits for the stream to complete and emits the last value (optionally matching a predicate).

import { of } from 'rxjs';
import { last } from 'rxjs/operators';

of(1, 4, 6, 9).pipe(
  last(x => x % 2 === 0)
).subscribe(console.log); // Output: 6

-----------skip------

5. skip – Ignore First N Values
The skip operator skips the first N emitted values, then emits the rest.

import { of } from 'rxjs';
import { skip } from 'rxjs/operators';

of(10, 20, 30, 40).pipe(
  skip(2)
).subscribe(console.log); //30  40
