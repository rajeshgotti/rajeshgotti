    how to create database and table

    Create Database & Table in SQL Server (SSMS)

    🚀 Step 1: Open SSMS

    👉 Open SQL Server Management Studio (SSMS)

    🚀 Step 2: Create New Database

    • Right-click on Databases
    • Select New Database

    Example

    studentDb
    • Click OK

    🚀 Step 3: Create New Table

    • Expand the database:
    studentDb
    • Right-click on Tables
    • Select New → Table

    🚀 Step 4: Add Columns

    Column Name Data Type
    studentId int
    studentName nvarchar(10)
    email nvarchar(40)

    🚀 Step 5: Set Primary Key

    • Right-click on:
    studentId
    • Select:
    Set Primary Key

    🚀 Step 6: Enable Identity (Auto Increment)

    👉 Select studentId row

    👉 At the bottom:

    Column Properties

    👉 Expand:

    Identity Specification

    👉 Double-click:

    (Is Identity)

    👉 Change:

    No → Yes

    📌 What is Identity?

    👉 Automatically generates IDs

    Example:

    1
2
3
4

    👉 No need to manually insert IDs.

    🚀 Step 7: Save Table

    👉 Click the Save button

    📍 Located: - Top toolbar - Left side of New Query button

    🚀 Step 8: Enter Table Name

    Example:

    studentTable

    👉 Click OK

    ✅ Final Result

    Database:

    studentDb

    Table:

    studentTable

    Columns:

    studentId
studentName
email

    ✅ Final Flow

    SSMS
  ↓
Create Database
  ↓
Create Table
  ↓
Add Columns
  ↓
Set Primary Key
  ↓
Enable Identity
  ↓
Save Table

    execute చేస్తుంది.

    🚀 Extra Spaces ఎందుకు వస్తున్నాయి?

    Swagger లో ఇలా కనిపిస్తే:

    "studentName": "Ravi     "

    👉 కారణం:

    Database column type:

    CHAR(100)

    CHAR fixed length కావడం వల్ల spaces add చేస్తుంది.

    ✅ Correct Fix

    ALTER TABLE studentTable
ALTER COLUMN studentName VARCHAR(100);

    లేదా:

    NVARCHAR(100)

    use చేయండి.
