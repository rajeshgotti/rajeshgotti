    Directive

    🧩 Angular Directives

    📌 Definition

    Directives are instructions in Angular that tell the DOM how to behave or change appearance.

    👉 They are used to: - Manipulate DOM - Add/remove elements - Modify styles or behavior

    🧱 Types of Directives (3 Types)

    1️⃣ Structural Directives

    👉 Used to change the structure of DOM (add/remove elements)

    ✅ Examples

    • *ngIf → conditionally show/hide elements
    • *ngFor → loop through data
    • *ngSwitch → switch-case rendering
    <div *ngIf="isVisible">
  Hello
</div>

<div *ngFor="let item of items">
  {{ item }}
</div>

    2️⃣ Attribute Directives

    👉 Used to change the appearance or behavior of elements

    ✅ Examples

    • ngClass
    • ngStyle
    • [disabled]
    • [hidden]

    ✅ ngClass Example

    <div [ngClass]="{ active: isActive }">
  Text
</div>

<button [disabled]="isDisabled">
  Click
</button>

    ✅ Dynamic Button Class Example

    <button
  [ngClass]="{
    'success-btn': status === 'success',
    'error-btn': status === 'error',
    'warning-btn': status === 'warning'
  }">

  Submit

</button>

    .success-btn {
  background-color: green;
  color: white;
}

.error-btn {
  background-color: red;
  color: white;
}

.warning-btn {
  background-color: orange;
  color: white;
}

    ✅ Card Example Using ngClass

    <div class="card"
  [ngClass]="{
    'high': temperature > 100,
    'normal': temperature <= 100
  }">

  Temperature: {{ temperature }}

</div>

    .card {
  padding: 10px;
  border-radius: 5px;
}

.card.high {
  background: red;
  color: white;
}

.card.normal {
  background: green;
  color: white;
}

    ✅ Angular Material Button Color Override

    .mat-mdc-raised-button.mat-primary {
  background-color: #1d75b8 !important;
}

    3️⃣ Component Directives (Custom Directives)

    👉 Components are also directives with their own template

    ✅ Example

    @Component({
  selector: 'app-demo',
  template: `<h1>Hello</h1>`
})
export class DemoComponent {}

    <app-demo></app-demo>

    ✅ Summary

    • Structural Directives → change DOM structure
      (*ngIf, *ngFor, *ngSwitch)

    • Attribute Directives → change style/behavior
      (ngClass, ngStyle, [disabled])

    • Component Directives → custom UI with template + logic

    🔀 ngIf 
    <div *ngIf="condition">
  This content will only be visible if 'condition' is true.
</div>

<!-- with else -->
<div *ngIf="condition; else elseBlock">
  This content is visible if 'condition' is true.
</div>

<ng-template #elseBlock>
  This content is visible if 'condition' is false.
</ng-template>

    ✅ Note

    • condition should be boolean in TS
    🙈 Hidden Property 
    <div [hidden]="isHidden">
  This content is hidden when 'isHidden' is true.
</div>

<button (click)="isHidden = !isHidden">Toggle Visibility</button>

    ✅ Note

    • Element stays in DOM, only hidden visually

    ??? note "🔁 ngSwitchCase"

    ```html
<div [ngSwitch]="status">
  <div *ngSwitchCase="'active'">The status is Active.</div>
  <div *ngSwitchCase="'inactive'">The status is Inactive.</div>
  <div *ngSwitchCase="'pending'">The status is Pending.</div>
  <div *ngSwitchDefault>The status is unknown.</div>
</div>
```

## ✅ Notes
- `ngSwitch` → main condition
- `ngSwitchCase` → match value
- `ngSwitchDefault` → fallback
    ⚙️ Switch Case (TypeScript) 
    updateFontSize(size: number) {
  const root = document.documentElement;
  let fontDefaultName = '';

  switch (size) {
    case 10:
      fontDefaultName = '--font-default-xsmall';
      break;
    case 12:
      fontDefaultName = '--font-default-small';
      break;
    case 13:
      fontDefaultName = '--font-default-lg';
      break;
    case 14:
      fontDefaultName = '--font-default-xl';
      break;
    case 15:
      fontDefaultName = '--font-default-xxl';
      break;
    case 16:
      fontDefaultName = '--font-default-xxxl';
      break;
    default:
      fontDefaultName = '--font-default-small';
  }

  root.style.setProperty(fontDefaultName, `${size}px`);
}

    <div *ngFor="let item of items">
  {{ item }}

      a
  b
  c
  d
  e
  f

    📌 With Index

    <ul>
  <li *ngFor="let item of items; let i = index">
    {{ i }} - {{ item }}
  </li>
</ul>

    📤 Output

      0 - Apple
  1 - Banana
  2 - Cherry

    ⚡ trackBy (Performance)

    items = ['Apple', 'Banana', 'Cherry'];

trackByFn(index: number, item: string) {
  return index; // or return item if values are unique
}

    <div *ngFor="let item of items; trackBy: trackByFn">
  {{ item }}
</div>

    📤 Output

    Apple
Banana
Cherry

    📏 Variable Naming Rules 
    let userName: string = 'John Doe';
let age: number = 25;

    ✅ Rules

    • Use camelCase
    • First letter → small
    • Next words → Capital

    📦 Array

    let fruits = ['apple', 'banana'];

    🧱 Object

    let objName = {
  key1: value1,
  key2: value2
