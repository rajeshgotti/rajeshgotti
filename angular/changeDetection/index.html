    Angular Change Detection - Telugu Brief Explanation

    What is Change Detection?

    Change Detection అనేది Angular యొక్క mechanism.

    Component (TypeScript) లో data change అయినప్పుడు, Angular automatically HTML (DOM/UI) ని update చేస్తుంది.

    Example

    this.patientName = 'John';

    {{ patientName }}

    Output

    John

    TypeScript లో value change అయితే, Angular automatically HTML ని refresh చేస్తుంది.

    Change Detection Strategies

    Angular లో రెండు Strategies ఉన్నాయి.

    Strategy Description Performance
    Default ప్రతి event, HTTP call, timer తరువాత మొత్తం application check చేస్తుంది Slow
    OnPush అవసరమైనప్పుడు మాత్రమే component check చేస్తుంది Fast

    OnPush ఎందుకు ఉపయోగించాలి?

    • Better Performance
    • Unnecessary rendering తగ్గుతుంది
    • Large Applications కి best
    • Predictable UI Updates
    • Supports Immutable Data

    OnPush Triggers

    OnPush component ఈ cases లో మాత్రమే refresh అవుతుంది.

    1. @Input() Reference Changes

    ✅ Correct

    this.patient = {
  ...this.patient,
  name: 'John'
};

    ❌ Wrong

    this.patient.name = 'John';

    Object reference change కాకపోతే OnPush update చేయదు.

    2. Component Events

    <button (click)="save()">
  Save
</button>

    Click event వచ్చినప్పుడు Angular refresh చేస్తుంది.

    3. Async Pipe

    {{ patientList$ | async }}

    Observable emit అయినప్పుడు Angular automatically update చేస్తుంది.

    4. ChangeDetectorRef

    this.cdr.markForCheck();

    Angular కి

    "Please refresh this component"

    అని చెప్పినట్లే.

    5. Angular Signals

    Signal value change అయితే Angular automatically update చేస్తుంది.

    markForCheck() vs detectChanges()

    Method Purpose
    markForCheck() Next Change Detection Cycle లో Refresh చేస్తుంది
    detectChanges() Immediately Refresh చేస్తుంది
    detach() Change Detection ని Stop చేస్తుంది
    reattach() Change Detection ని Start చేస్తుంది

    Recommended

    this.cdr.markForCheck();

    Immediate Refresh

    this.cdr.detectChanges();

    Best Practices

    ✅ Always use OnPush

    ✅ Prefer Async Pipe

    ✅ Use Immutable Updates

    this.list = [
  ...this.list,
  newItem
];

    ✅ Use trackBy with *ngFor

    <div
  *ngFor="
    let item of list;
    trackBy: trackById
  ">
</div>

    Avoid

    ❌ Calling methods inside template

    {{ getName() }}

    Instead

    this.name = this.getName();

    {{ name }}

    ❌ Avoid

    this.list.push(item);

    Instead

    this.list = [
  ...this.list,
  item
];

    ❌ Don't call

    this.cdr.detectChanges();

    repeatedly inside loops.

    Angular Change Detection — OnPush Strategy

    Change Detection అంటే ఏంటి?

    Angular లో Change Detection అనేది component లోని data change అయినప్పుడు, ఆ change ని detect చేసి UI (HTML view) ని automatically update చేసే mechanism.

    అంటే variable value మారితే, screen మీద కనిపించే value కూడా update అవుతుంది.

    Default Strategy vs OnPush

    Default Change Detection

    Default strategy లో Angular ప్రతి చిన్న event వచ్చినప్పుడు components ని check చేస్తుంది.

    ఉదాహరణకు:

    • Button click
    • HTTP response
    • setTimeout
    • Mouse event
    • Keyboard event

    Components ఎక్కువగా ఉన్నప్పుడు unnecessary checks జరగడం వల్ల performance తగ్గే అవకాశం ఉంటుంది.

    OnPush Change Detection

    ChangeDetectionStrategy.OnPush వాడితే Angular ఆ component ని అవసరమైనప్పుడు మాత్రమే check చేస్తుంది.

    సాధారణంగా ముఖ్యమైన cases:

    • @Input() property reference change అయినప్పుడు
    • Component లో event fire అయినప్పుడు
    • async pipe emit చేసినప్పుడు
    • Manually markForCheck() లేదా detectChanges() call చేసినప్పుడు

    దీని వల్ల unnecessary change detection checks తగ్గి performance improve అవుతుంది.

    Example

    import { ChangeDetectionStrategy, ChangeDetectorRef } from '@angular/core';

@Component({
  selector: 'app-dynamicpatient-information',
  templateUrl: './dynamicpatient-information.component.html',
  changeDetection: ChangeDetectionStrategy.OnPush
})
export class DynamicPatientInformationComponent {

  constructor(
    private changeDetectorRef: ChangeDetectorRef
  ) {}

}

    ఇక్కడ:

    ChangeDetectionStrategy.OnPush

    component కి OnPush change detection strategy enable చేస్తుంది.

    ChangeDetectorRef

    change detection ని manually control చేయడానికి ఉపయోగిస్తాం.

    markForCheck() ఎందుకు use చేస్తాం?

    OnPush component లో async operation ద్వారా data update అయినప్పుడు కొన్నిసార్లు Angular కి ఆ component ని check చేయమని manually చెప్పాలి.

    ఉదాహరణ:

    this.patientService.getPatient().subscribe((data) => {

  this.patientData = data;

  this.changeDetectorRef.markForCheck();

});

    ఇక్కడ API response వచ్చిన తర్వాత:

    API Response
     ↓
patientData update
     ↓
markForCheck()
     ↓
Angular component ని check చేస్తుంది
     ↓
UI update అవుతుంది

    markForCheck() అంటే:

    "Angular, ఈ component data change అయింది. Next change detection cycle లో ఈ component ని check చేయి."

    detectChanges()

    detectChanges() కూడా change detection కోసం ఉపయోగిస్తాం.

    this.patientData = data;

this.changeDetectorRef.detectChanges();

    detectChanges() ఉపయోగిస్తే ఆ component మీద change detection ని immediately run చేయమని Angular కి చెప్తాం.

    markForCheck() vs detectChanges()

    Method Meaning
    markForCheck() Next change detection cycle లో component ని check చేయమని mark చేస్తుంది
    detectChanges() వెంటనే change detection run చేస్తుంది

    Real-Time Project లో ఎందుకు OnPush use చేస్తాం?

    పెద్ద applications లో చాలా components ఉంటాయి.

    Patient Information, Chart, Reports, Forms, Tables, WebSocket updates లాంటి components లో unnecessary change detection తగ్గించడానికి OnPush ఉపయోగిస్తాం.

    Interview Answer

    Change Detection is the mechanism Angular uses to detect data changes and update the UI. By default Angular performs change detection frequently, whereas OnPush reduces unnecessary checks and improves performance. In OnPush components, when data is updated through asynchronous operations, we can use markForCheck() to tell Angular to check the component in the next change detection cycle.
