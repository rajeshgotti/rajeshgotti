    ---- How to Use Local Storage in Angular --------

    1. Set a Value
   localStorage.setItem('username', 'Rajesh');
2. Get a Value
   const name = localStorage.getItem('username');
   console.log(name);
3. Remove a Value
   localStorage.removeItem('username');
4. Clear All Local Storage
   localStorage.clear();
