    debounceTime

    using debounce distinctUntilChanged switchmap

    debouce type 
    ngOnInit() {

  this.searchControl.valueChanges
    .pipe(

      debounceTime(300),

      distinctUntilChanged(),

      switchMap(value =>

        this.apiService.search(value)

      )

    )
    .subscribe(results => {

      this.items = results;

    });

}

    1. debounceTime(300)

    User typing complete అయ్యే వరకు wait చేస్తుంది.

    h
he
hel
hell
hello

    Without debounceTime():

    GET /search?h
GET /search?he
GET /search?hel
GET /search?hell
GET /search?hello

    With debounceTime():

    GET /search?hello

    2. distinctUntilChanged()

    Prevents duplicate consecutive values.

    if User hello ani type chesadu accidentally types same value again hello then 2 times api call avtundi this is the problem:

    Without distinctUntilChanged():

    GET /search?hello
GET /search?hello

    2 identical API calls happen.

    With distinctUntilChanged():

    GET /search?hello

    Only one API call.

    3. switchMap()

    This is the most important for autocomplete.

    It cancels old API requests when new typing happens.

    Problem without switchMap

    Suppose:

    User types:

    a
ab
abc

    API response times:

    a    -> 5 seconds
ab   -> 2 seconds
abc  -> 1 second

    Responses come back like:

    abc  result arrives first
ab   result arrives later
a    result arrives last

    Now UI incorrectly shows old "a" result.

    switchMap() solution

    switchMap(value =>

  this.apiService.search(value)

)

    When new value comes:

    previous API call is cancelled
only latest request matters

    So:

    a    cancelled
ab   cancelled
abc  active

    Only "abc" result updates UI.

    debounceTime Example 
    import { debounceTime, takeUntil } from 'rxjs';

ngOnInit() {
  if (this.patientId) {
    this.hospitalizationForm.get('icdDescription')?.valueChanges.pipe(debounceTime(500),
        takeUntil(this.onDestroy$)).subscribe(res => {
         this.getProblemSuggestions(res);
      });
  }
}
problems = [];
getProblemSuggestions(value): void {
  if (value?.length > 2) {
    this.erdashboard.getICDData(value, false).pipe(takeUntil(this.onDestroy$))
      .subscribe(res => { 
       this.problems = res.body;
      });
   }
}
