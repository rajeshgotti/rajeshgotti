    use of trackBy

    *ngFor & trackBy

    *ngFor

    *ngFor అనేది Angular లో list లో ఉన్న items ని repeat చేసి చూపించడానికి ఉపయోగిస్తారు.

    <div *ngFor="let user of users">
  {{ user.name }}
</div>

    ఇక్కడ users array లో ఉన్న ప్రతి user కోసం ఒక <div> create అవుతుంది, మరియు ఆ user యొక్క name display అవుతుంది.

    Example

    users = [
  { id: 1, name: 'Ravi' },
  { id: 2, name: 'Sita' }
];

    Browser Output:

    <div>Ravi</div>
<div>Sita</div>

    trackBy ఎందుకు ఉపయోగిస్తారు?

    Angular కి list లో ఏ item మారిందో గుర్తించడానికి trackBy సహాయపడుతుంది.

    సమస్య ఏమిటి?

    users list update అయినప్పుడు Angular మొత్తం list ని మళ్లీ render చేయవచ్చు.

    ఇది performance ని slow చేస్తుంది, ముఖ్యంగా పెద్ద lists లో.

    trackBy ఉపయోగిస్తే?

    Angular ప్రతి item ని unique id ద్వారా గుర్తిస్తుంది.

    అప్పుడు మారిన item మాత్రమే update అవుతుంది, మిగతావి reuse అవుతాయి.

    Simple Telugu Explanation

    trackBy ఉపయోగించడం వల్ల Angular list లోని items ని unique గా గుర్తిస్తుంది.

    దాంతో unnecessary గా DOM elements మళ్లీ create చేయకుండా existing elements ని reuse చేస్తుంది.

    ఇది performance ని improve చేస్తుంది.

    Example with trackBy

    <div *ngFor="let user of users; trackBy: trackByUser">
  {{ user.name }}
</div>

    trackByUser(index: number, user: any): number {
  return user.id;
}

    ఇక్కడ Angular user.id ని ఉపయోగించి ప్రతి user ని గుర్తిస్తుంది.

    combine latest combineLatest

    queryParams$ = this._store.select(QueryParamsState.queryParams);
userIdPhyId$ = this._store.select(storeUserIdPhyIdState.getUserIdPhyId);

ngOnInit(): void {
   combineLatest([
       this.queryParams$,
       this.userIdPhyId$
        ]).pipe(takeUntil(this.onDestroy$)).subscribe(([params, results]) => {

        if (params) {
            this.moduleMnemonic = params.moduleMnemonic;
            this.pageMnemonic = params.pageMnemonic;
        }

        });
    }
    ఈ code లో combineLatest() ఎలా పని చేస్తుంది?

    📌 ఇక్కడ ఉన్న Observables

    Observable 1

    this.queryParams$

    Store నుండి query parameters తీసుకుంటుంది.

    Example:

    {
  moduleMnemonic: "MEDICATION",
  pageMnemonic: "HOME"
}

    Observable 2

    this.userIdPhyId$

    Store నుండి user information తీసుకుంటుంది.

    Example:

    {
  userId: 1001,
  physicianId: 2001,
  locationId: 3001
}

    📌 combineLatest() ఎందుకు వాడారు?

    ఈ component కి రెండు data sources అవసరం:

    • Query Parameters
    • User Details

    రెండూ వచ్చిన తర్వాత మాత్రమే code execute కావాలి.

    అందుకే:

    combineLatest([
  this.queryParams$,
  this.userIdPhyId$
])

    వాడారు.

    📌 Step 1

    Suppose:

    queryParams$

    value emit చేసింది.

    {
  moduleMnemonic: "MEDICATION",
  pageMnemonic: "HOME"
}

    కానీ:

    userIdPhyId$

    ఇంకా emit చేయలేదు.

    Result

    subscribe() execute కాదు

    ఎందుకంటే combineLatest() కి అన్ని Observables నుండి కనీసం ఒక్క value కావాలి.

    📌 Step 2

    తర్వాత:

    userIdPhyId$

    emit చేసింది.

    {
  userId: 1001,
  physicianId: 2001
}

    ఇప్పుడు రెండు Observables values ఉన్నాయి.

    Result

    subscribe(([params, results]) => {})

    execute అవుతుంది.

    📌 params లో ఏముంటుంది?

    params

    value:

    {
  moduleMnemonic: "MEDICATION",
  pageMnemonic: "HOME"
}

    📌 results లో ఏముంటుంది?

    results

    value:

    {
  userId: 1001,
  physicianId: 2001,
  locationId: 3001
}

    📌 Array Destructuring

    ([params, results])

    అంటే:

    params  = queryParams$ value
results = userIdPhyId$ value

    📌 తర్వాత ఏమవుతుంది?

    this.moduleMnemonic = params.moduleMnemonic;

    Example:

    this.moduleMnemonic = "MEDICATION";

    this.pageMnemonic = params.pageMnemonic;

    Example:

    this.pageMnemonic = "HOME";

    📌 Latest Value Concept

    Suppose:

    మొదట:

    queryParams$ = HOME
userIdPhyId$ = User1

    Output:

    HOME + User1

    తర్వాత:

    queryParams$ = DASHBOARD

    మాత్రమే change అయింది.

    combineLatest() latest values తీసుకుని మళ్లీ execute చేస్తుంది.

    Output:

    DASHBOARD + User1

    తర్వాత:

    userIdPhyId$ = User2

    Output:

    DASHBOARD + User2

    📌 takeUntil(this.onDestroy$)

    .pipe(takeUntil(this.onDestroy$))

    Component destroy అయినప్పుడు

    unsubscribe()

    అవుతుంది.

    Memory leaks రాకుండా ఉండటానికి ఇది ఉపయోగిస్తారు.

    📌 Real-Time Analogy

    Suppose:

    Query Params  = Patient Screen
User Details  = Logged In Doctor

    Screen open అయ్యేటప్పుడు:

    Patient Screen
        +

    రెండూ వచ్చిన తర్వాత మాత్రమే component work చేయాలి.

    అందుకే combineLatest() ఉపయోగించారు.
