    What Is localStorage?
localStorage is a Web API that allows you to store key-value pairs in the user's browser permanently 
(until explicitly cleared).Stored data persists across page reloads.All data is stored as strings.

    Local Storage - Telugu Brief Explanation

    LocalStorage అంటే ఏమిటి?

    LocalStorage అనేది Browser లో data ని store చేయడానికి ఉపయోగించే Web Storage.

    • Data Key-Value Pair format లో store అవుతుంది.
    • Browser close చేసినా కూడా data delete అవదు.
    • Manually delete చేసినప్పుడు లేదా localStorage.clear() చేసినప్పుడు మాత్రమే delete అవుతుంది.

    Key Points

    • ✅ Data String format లో మాత్రమే store అవుతుంది.
    • ✅ Size Limit: 5 MB - 10 MB (Browser based).
    • ✅ Same Domain లో మాత్రమే access చేయవచ్చు.
    • ✅ Server కి send అవదు (Client-side only).

    CRUD Operations

    1. Save Data - setItem()

    localStorage.setItem('key', 'value');

// Example
localStorage.setItem('username', 'Rajesh');
localStorage.setItem('empId', '101');

    2. Read Data - getItem()

    const name = localStorage.getItem('username');

console.log(name); // Rajesh

// Key lekapothe
const data = localStorage.getItem('xyz');

console.log(data); // null

    3. Delete One Item - removeItem()

    localStorage.removeItem('username');

    Only username key delete అవుతుంది.

    4. Delete Everything - clear()

    localStorage.clear();

    LocalStorage లో ఉన్న అన్ని keys delete అవుతాయి.

    Store Object / Array

    LocalStorage String మాత్రమే accept చేస్తుంది.

    అందుకే Object లేదా Array store చేయాలంటే JSON.stringify() ఉపయోగించాలి.

    LocalStorage vs SessionStorage vs Cookies

    Feature LocalStorage SessionStorage Cookies
    Expiry Never Tab Close Configured Time
    Size 5-10 MB 5-10 MB 4 KB

    Important Notes

    • ❌ Sensitive Tokens store చేయకండి.

    removeItem() Delete One Key
    clear() Delete All Keys
    JSON.stringify() Object → String
    JSON.parse() String → Object

    Remember

    ✅ getItem() → Read

    ✅ removeItem() → Delete One

    ✅ clear() → Delete All

    Component

    import { Component, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FormControl, FormGroup, ReactiveFormsModule } from '@angular/forms';
import { MatSnackBar } from '@angular/material/snack-bar';
import { MatFormFieldModule } from '@angular/material/form-field';
import { MatInputModule } from '@angular/material/input';

@Component({
  selector: 'app-demo',
  standalone: true,
  imports: [
    CommonModule,
    ReactiveFormsModule,
    MatFormFieldModule,
    MatInputModule
  ],
  templateUrl: './demo.html'
})
export class Demo implements OnInit {

  records: any[] = [];

  demoForm = new FormGroup({
    empid: new FormControl(''),
    empFName: new FormControl(''),
    empLName: new FormControl(''),
    middleName: new FormControl('')
  });

  constructor(private snack: MatSnackBar) {}

  ngOnInit(): void {}

  // CREATE
  saveEmp() {

    const obj = this.demoForm.value;

    const data = localStorage.getItem('empData');

    const empList = data
      ? JSON.parse(data)
      : [];

    empList.push(obj);

    localStorage.setItem(
      'empData',
      JSON.stringify(empList)
    );

    this.snack.open(
      'Saved Successfully',
      'OK',
      { duration: 2000 }
    );

    this.demoForm.reset();
  }

  // READ
  viewRecords() {

    const data =
      localStorage.getItem('empData');

    this.records = data
      ? JSON.parse(data)
      : [];

    this.snack.open(
      `Total ${this.records.length} Records`,
      'OK',
      { duration: 2000 }
    );
  }

  // EDIT
  empEdit(id: string) {

    const data =
      localStorage.getItem('empData');

    const empList = data
      ? JSON.parse(data)
      : [];

    const emp = empList.find(
      (x: any) => x.empid === id
    );

    if (emp) {

      this.demoForm.patchValue({
        empid: emp.empid,
        empFName: emp.empFName,
        empLName: emp.empLName,
        middleName: emp.middleName
      });

    }

  }

  // DELETE
  delete(id: string) {

    const data =
      localStorage.getItem('empData');

    const empList = data
      ? JSON.parse(data)
      : [];

    const updated = empList.filter(
      (x: any) => x.empid !== id
    );

    localStorage.setItem(
      'empData',
      JSON.stringify(updated)
    );

    this.records = updated;

    this.snack.open(
      'Record Deleted',
      'OK',
      { duration: 2000 }
    );

  }

  // CLEAR ALL
  clearAllStorage() {

    localStorage.clear();

    this.records = [];

    this.snack.open(
      'LocalStorage Cleared',
      'OK',
      { duration: 2000 }
    );

  }

}
