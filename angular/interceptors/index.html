    Interceptor

    HTTP Interceptors - Telugu Brief Explanation

    What is an Interceptor?

    Interceptor అనేది Angular లో HTTP Request మరియు Response మధ్యలో పనిచేసే Middle Layer (Middleware).

    Component నుండి API కి Request వెళ్లే ముందు, అది ముందుగా Interceptor ద్వారా వెళ్తుంది.

    అలాగే Server నుండి వచ్చే Response కూడా ముందుగా Interceptor ద్వారా Component కి వస్తుంది.

    Why Use Interceptors?

    ఒకే Code ని ప్రతి API Call దగ్గర రాయకుండా,

    ఒకసారి Interceptor లో రాస్తే,

    మొత్తం Application లో Automatically Apply అవుతుంది.

    Common Uses

    • JWT Token Add చేయడం
    • Loading Spinner Show చేయడం
    • Error Handling
    • Retry Failed Requests
    • Logging
    • Caching
    • Common Headers Add చేయడం
    • Base URL Add చేయడం

    JWT Interceptor Example

    export const jwtInterceptor:
HttpInterceptorFn = (req, next) => {

  const token =
    localStorage.getItem('token');

  if (token) {

    req = req.clone({

      setHeaders: {

        Authorization:
        `Bearer ${token}`

      }

    });

  }

  return next(req);

};

    How It Works

    Step 1

    Request URL Check చేస్తుంది.

    if (
  req.url.startsWith(
    AppConfigData.imageBaseUrl
  )
) {

}

    Step 2

    Token తీసుకుంటుంది.

    const token =
  localStorage.getItem(
    'imageToken'
  );

    Step 3

    Request Clone చేస్తుంది.

    req = req.clone({

  setHeaders: {

    Authorization:
    `Bearer ${token}`

  }

});

    Why clone()?

    Angular HTTP Requests Immutable.

    Directగా Modify చేయలేము.

    అందుకే clone() ఉపయోగిస్తాం.

    Step 4

    Server కి పంపుతుంది.

    return next(req);

    next(req) లేకపోతే

    API Call Server కి వెళ్లదు.

    Best Practices

    ✅ Always use req.clone()

    ✅ Keep Authentication Logic inside Interceptor

    ✅ Handle Common Errors

    ✅ Use switchMap() for Async Token Refresh

    ❌ Don't write Business Logic

    ❌ Don't modify Request directly

    ❌ Don't log Passwords or Sensitive Data
