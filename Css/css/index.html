 note:ms :margin starting 
     =>from bootstarap 5 m = margin 
      s = start (which means left side in left-to-right languages) 
     auto = automatic margin — it tells the browser to automatically take up available space

    ( [me(margin-end) means margin right] - [ms(margin-start)- ante margin left ani ])

    | Syntax                         
 ------------------------------ 
 `margin: 10px;`          
         : All sides = `10px`
 `margin: 10px 20px;`                       
         : T/b=10px,L&R=`20px`
 `margin: 10px 20px 30px;`      
         : T:10px, L/R:20px, b:30px
 `margin: 10px 20px 30px 40px;` 
         : T=10px,R:20px,B:30px,L:40px

padding: 10px 15px 20px 25px;
padding: TOP RIGHT BOTTOM LEFT;

| Syntax                          | Meaning                                                      |
| ------------------------------- | ------------------------------------------------------------ |
| `padding: 10px;`                | All sides = `10px` (top, right, bottom, left)                |
| `padding: 10px 20px;`           | Top & bottom = `10px`, left & right = `20px`                 |
| `padding: 10px 20px 30px;`      | Top = `10px`, left & right = `20px`, bottom = `30px`         |
| `padding: 10px 20px 30px 40px;` | Top = `10px`, right = `20px`, bottom = `30px`, left = `40px` |

    ===margin===

✅ Margin size scale (rem and px equivalents):
Num  rem      px 
0    0rem     0px
1    0.25rem  4px
2    0.5rem   8px
3    1rem     16px
4    1.5rem   24px
5    3rem     48px

    | Bootstrap | Side(s) affected               | Explanation                |
| ----------| ------------------------------ | -------------------------- |
|  m-2      | margin-all sides (16px) 
| `mt-3`    | Margin **top**                 | Margin top = 1rem          |
| `mb-3`    | Margin **bottom**              | Margin bottom = 1rem       |
| `ms-3`(mr-left)    | Margin **start** (left in LTR) | Margin start (left) = 1rem |
| `me-3`(mr-right)    | Margin **end** (right in LTR)  | Margin end (right) = 1rem  |
| `mx-3`    | Margin **left and right**      | Horizontal margin = 1rem   |
| `my-3`    | Margin **top and bottom**      | Vertical margin = 1rem     |
