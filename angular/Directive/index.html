    Directive

    🧩 Angular Directives

    📌 Definition

    Directives are instructions in Angular that tell the DOM how to behave or change appearance.

    👉 They are used to manipulate DOM, add/remove elements, or modify styles/behavior.

    🧱 Types of Directives (3 Types)

    1️⃣ Structural Directives

    👉 Used to change the structure of DOM (add/remove elements)

    Examples: - *ngIf → conditionally show/hide elements
    - *ngFor → loop through data
    - *ngSwitch → switch-case rendering 

    <div *ngIf="isVisible">Hello</div>

<div *ngFor="let item of items">
  {{item}}
</div>

    2️⃣ Attribute Directives

    👉 Used to change appearance or behavior of elements

    Examples: - ngClass → add/remove CSS classes
    - ngStyle → apply styles
    - [disabled], [hidden] 

    <div [ngClass]="{active: isActive}">Text</div>

<button [disabled]="isDisabled">Click</button>

    3️⃣ Component Directives (or) Custom Directive

    👉 Components are also directives with a template

    Example: 

    @Component({
  selector: 'app-demo',
  template: `<h1>Hello</h1>`
})


    <app-demo></app-demo>

    ✅ Summary

    • Structural → change DOM structure (*ngIf, *ngFor)
    • Attribute → change style/behavior (ngClass, ngStyle)
    • Component → custom UI (template + logic)
    🔀 ngIf 
    <div *ngIf="condition">
  This content will only be visible if 'condition' is true.
</div>

<!-- with else -->
<div *ngIf="condition; else elseBlock">
  This content is visible if 'condition' is true.
</div>

<ng-template #elseBlock>
  This content is visible if 'condition' is false.
</ng-template>

    ✅ Note

    • condition should be boolean in TS
    🙈 Hidden Property 
    <div [hidden]="isHidden">
  This content is hidden when 'isHidden' is true.
</div>

<button (click)="isHidden = !isHidden">Toggle Visibility</button>

    ✅ Note

    • Element stays in DOM, only hidden visually

    ??? note "🔁 ngSwitchCase"

    ```html
<div [ngSwitch]="status">
  <div *ngSwitchCase="'active'">The status is Active.</div>
  <div *ngSwitchCase="'inactive'">The status is Inactive.</div>
  <div *ngSwitchCase="'pending'">The status is Pending.</div>
  <div *ngSwitchDefault>The status is unknown.</div>
</div>
```

## ✅ Notes
- `ngSwitch` → main condition
- `ngSwitchCase` → match value
- `ngSwitchDefault` → fallback
    ⚙️ Switch Case (TypeScript) 
    updateFontSize(size: number) {
  const root = document.documentElement;
  let fontDefaultName = '';

  switch (size) {
    case 10:
      fontDefaultName = '--font-default-xsmall';
      break;
    case 12:
      fontDefaultName = '--font-default-small';
      break;
    case 13:
      fontDefaultName = '--font-default-lg';
      break;
    case 14:
      fontDefaultName = '--font-default-xl';
      break;
    case 15:
      fontDefaultName = '--font-default-xxl';
      break;
    case 16:
      fontDefaultName = '--font-default-xxxl';
      break;
    default:
      fontDefaultName = '--font-default-small';
  }

  root.style.setProperty(fontDefaultName, `${size}px`);
}
