    Validations

    ASP.NET Core — DTO Validation

    1. Create MobileRequestDto

    using System.ComponentModel.DataAnnotations;

namespace Mobile.DTOs
{
    public class MobileRequestDto
    {
        [Required(ErrorMessage = "Mobile name is required")]
        public string MobileName { get; set; }

        [Required(ErrorMessage = "Mobile model is required")]
        public string MobileModel { get; set; }

        [Range(1, 10000000, ErrorMessage = "Price must be greater than 0")]
        public decimal Price { get; set; }
    }
}

    2. Validation Rules

    MobileName
    ↓
[Required]
    ↓
Cannot be empty

    MobileModel
    ↓
[Required]
    ↓
Cannot be empty

    Price
    ↓
[Range(1, 10000000)]
    ↓
Must be between 1 and 10,000,000

    3. Controller Does Not Need Manual Validation

    Because the controller has:

    [ApiController]

    ASP.NET Core automatically checks the DTO validation rules.

    Therefore, manual validation like:

    if (!ModelState.IsValid)
{
    return BadRequest(ModelState);
}

    is normally not required when using [ApiController].

    4. Controller

    [HttpPost]
public IActionResult PostMobile(MobileRequestDto mobile)
{
    var result = _service.AddMobile(mobile);

    return Ok(result);
}
