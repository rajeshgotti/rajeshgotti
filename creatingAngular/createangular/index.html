    NewProject

    creating project including Angular/Bootstrap/Material/Ag-grid

    Angular + Angular Material + Bootstrap + AG Grid Setup

    🚀 1. Create Angular Project (with SCSS)

    Run:

    ng new emr-demo

    ❓ “Which stylesheet format would you like to use?”
    👉 Select: SCSS

    ❓ “Do you want to enable Server-Side Rendering (SSR) and Static Site Generation (SSG/Prerendering)?”
    👉 Select: N

    ✅ Why NOT SSR?

    You are building an EMR / dashboard / internal application.

    SSR is mainly used for: - SEO websites - Public content pages - Faster initial page load for public sites

    👉 SSR adds unnecessary complexity for your use case.

    ❓ “Do you want to create a 'zoneless' application without zone.js?”
    👉 Select: N

    🚀 2. Enter the Project Folder

    cd emr-demo

    🚀 3. Install Angular Material

    Run:

    ng add @angular/material

    ❓ “Would you like to share pseudonymous usage data about this project with the Angular Team?”
    👉 Recommended: N

    ❓ The package @angular/material will be installed and executed. Would you like to proceed? (Y/n)
    👉 Select: Y

    🚀 4. Install Bootstrap

    npm install bootstrap

    🚀 5. Install AG Grid

    npm install ag-grid-community ag-grid-angular

    🚀 6. Register AG Grid

    main.ts

    import { bootstrapApplication } from '@angular/platform-browser';
import { appConfig } from './app/app.config';
import { App } from './app/app';

import { ModuleRegistry, AllCommunityModule } from 'ag-grid-community'; //add this line

ModuleRegistry.registerModules([AllCommunityModule]); // add this line

bootstrapApplication(App, appConfig)
  .catch((err) => console.error(err));

    🚀 7. Import AG Grid in your Component.ts file

    import { AgGridModule } from 'ag-grid-angular';

@Component({
  standalone: true,
  imports: [AgGridModule]
})

    🚀 8. Add Global Styles

    angular.json

    "styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "node_modules/ag-grid-community/styles/ag-grid.css",
  "node_modules/ag-grid-community/styles/ag-theme-alpine.css",
  "src/styles.scss"
]

    ✅ Setup Completed Successfully

    🧩 Angular Setup & Basic Routing (Step-by-Step)

    🚀 Project Setup

     step:1 npm install -g @angular/cli    
 step:2 ng new yourProjectName                       EX: ng new Employee
 step:3 move to ur directory -> cd yourProjectName   EX: cd Employee

    Install UI Libraries (Bootstrap + Angular Material)

    npm i bootstrap
ng add @angular/material

    👉 After installing, open angular.json and add styles:

    "styles": [
  "@angular/material/prebuilt-themes/azure-blue.css",
  "node_modules/bootstrap/dist/css/bootstrap.css"
]

    Create Components & Services

    # Create a component
ng g c compName

# Create a service
ng g s serviceName

    🔗 Add Routing in HTML

    Open app.component.html and add:

    <button class="btn btn-primary" routerLink="/parent">Student</button>
<router-outlet></router-outlet>

    👉 router-outlet is where your pages will load.

    🛣️ Configure Routes

    Open app.routes.ts:

    export const routes: Routes = [
  { path: 'parent', component: Parent },
  { path: 'child', component: Child }
];

    📦 Import Router Module

    Open app.ts (or main module):

    imports: [RouterOutlet, RouterModule]

    ▶️ Run the Application

    # Normal run
ng s
ng s --open   # opens browser automatically

# Run on specific port
ng s --port 2423

# Run with custom host + port
ng s --host 192.168.21.59 --port 4200

    ✅ Now your Angular project is ready with routing and UI libraries!

    🔗 Angular API Integration (Step-by-Step Guide)

    🧩 Step 1: Create Environment File

    👉 Define your API base URL and endpoints

    export const environment = {
  baseUrl: 'https://localhost:7014/api/',  // Swagger URL
  Student: 'Students'
}

    ⚙️ Step 2: Configure HttpClient

    📄 File: app.config.ts

    👉 Add HttpClient provider

    providers: [
  provideHttpClient(), // required for API calls
]

    🔧 Step 3: Create Service (API Call)

    📄 File: student.service.ts

    import { HttpClient } from '@angular/common/http';
import { Injectable } from '@angular/core';
import { environment } from '../environments/environment';

@Injectable({ providedIn: 'root' })
export class StudentService {

  constructor(private http: HttpClient) {}

  getStudent() {
    return this.http.get(environment.baseUrl + environment.Student);
  }
}

    📦 Step 4: Use Service in Component

    📄 File: student.component.ts

    import { Component, OnInit } from '@angular/core';
import { StudentService } from './student.service';

@Component({
  selector: 'app-student',
  templateUrl: './student.component.html'
})
export class StudentComponent implements OnInit {

  mydata: any;

  constructor(private ser: StudentService) {}

  ngOnInit() {
    this.data();
  }

  data() {
    this.ser.getStudent().subscribe({
      next: (res) => {
        console.log(res, 'res');
        this.mydata = res;
      }
    });
  }
}

    🚫 CORS Error Fix (.NET Backend)

    👉 If you get CORS error, update your backend

    📄 File: Program.cs

    builder.Services.AddDbContext<StudentDbContext>(options =>
    options.UseSqlServer(builder.Configuration.GetConnectionString("DefaultConnection")));

// Enable CORS
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowAngularClient",
        policy =>
        {
            policy.WithOrigins("http://localhost:4200") // Angular app URL
                  .AllowAnyHeader()
                  .AllowAnyMethod();
        });
});

app.UseHttpsRedirection();
app.UseCors("AllowAngularClient"); // enable CORS
app.UseAuthorization();

    ✅ Now your Angular app can successfully call backend APIs without CORS issues.
