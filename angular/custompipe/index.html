    DatePipe

    📅 Angular DatePipe Usage

    🪜 Steps

    Step 1: Inject DatePipe 

    private _datePipe = inject(DatePipe);

    Step 2: Use transform() method to format date. DataPipe lo manaki transform() ane method vuntundi e method ni use chesi mana date ni manaki nachina format ki change cheskovachu ex: this._datePipe.transform(....)

    Example

    private _datePipe = inject(DatePipe); // import DatePipe

this.vaccineLotList = event?.lotVaccines?.map((ele: any) => {
  return {
    lotNumber: ele?.lotNumber,
    expireDate: this._datePipe.transform(ele?.expireDate, 'dd/MM/yyyy') // formatted date
  };
}) || [];

    📤 Sample Output

    Input:
ele.expireDate = '2026-04-16T00:00:00'

Output:
expireDate = '16/04/2026'

    ⚠️ Important Notes

    • Always check if date is valid before transforming
    • Returns null if value is empty/invalid
    • Works only if DatePipe is provided in app/module
    providers: [DatePipe]

    RealTime Example

    🧾 Angular [innerHTML] Usage Example 

    Syntax: [innerHTML]="yourVariable"

    ⚙️ TypeScript (Component)

    viewtext: any; // declare variable
htmlView: any; // declare variable

if (data) {
  this.convertBlobToXmlString(data?.alldata).then((xmlString) => {
    const divEle = document.createElement('div');

    divEle.innerHTML = xmlString; // assigne value to that above variable

    this.htmlView = divEle.innerHTML;  // for HTML preview
    this.viewtext = divEle.innerHTML;  // for text preview

  }).catch((error) => {
    console.error("Error reading Blob:", error);
  });
}

    🧩 HTML Template

    <!-- Text Preview -->
<div *ngIf="data.fileType === 'txt'">
  <strong>Text Preview</strong>
  <div class="modal_body" mat-dialog-content>
    <div [innerHTML]="viewtext"></div> //here we use that variable ex: [innerHtml]=""
  </div>
</div>

<!-- HTML Preview -->
<div *ngIf="data.fileType === 'htm' || data.fileType === 'html'">
  <strong>HTML Preview</strong>
  <div class="modal_body" mat-dialog-content>
    <div [innerHTML]="htmlView"></div>
  </div>
</div>

    ✅ Output

    • Displays formatted HTML content inside div
    • Renders tags like <b>, <p>, <table> properly
    • Works for both text and HTML file preview

    ⚠️ Important Notes

    • [innerHTML] renders raw HTML content
    • Be careful with unsafe HTML (XSS risk)
    • If needed, use Angular DomSanitizer
    constructor(private sanitizer: DomSanitizer) {}

this.htmlView = this.sanitizer.bypassSecurityTrustHtml(xmlString);
