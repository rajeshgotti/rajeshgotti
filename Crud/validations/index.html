    All Validations

    1. Clear Validation

    this.patientInfoForm.get('genderIdentity')?.clearValidators();

this.patientInfoForm.get('genderIdentity')?.updateValueAndValidity();

**Why updateValueAndValidity()?**

this.form.get('email')?.clearValidators();
ఇక్కడ validators remove అయ్యాయి.
కానీ Angular కి ఇంకా old validation status ఉండొచ్చు
అందుకే:
this.form.get('email')?.updateValueAndValidity();
వాడితే Angular:
✅ కొత్త validators తో మళ్లీ check చేస్తుంది
✅ field valid/invalid update అవుతుంది
✅ errors clear అవుతాయి
Simple Telugu Meaning
updateValueAndValidity() అంటే
"Field validation ని మళ్లీ refresh చేయడం" లేదా
"కొత్త validators ప్రకారం మళ్లీ check చేయడం".
After changing validators, Angular must refresh validation status.

    Angular Form Control States
    Property Meaning ఎప్పుడు true అవుతుంది Use
    touched యూజర్ field‌ని touch చేశాడు (focus → blur) field‌లోకి వెళ్లి బయటకు వచ్చినప్పుడు error messages చూపడానికి
    untouched ఇంకా touch చేయలేదు default state మొదట్లో errors hide చేయడానికి
    dirty value change అయ్యింది user value మార్చినప్పుడు user changes detect చేయడానికి
    pristine value change కాలేదు initial state form reset/initial check కోసం
    valid errors లేవు అన్ని validations pass అయితే submit enable చేయడానికి
    invalid errors ఉన్నాయి ఏదైనా validation fail అయితే error messages చూపడానికి
    pending async validation జరుగుతోంది server validation wait లో ఉన్నప్పుడు loading చూపించడానికి
    disabled field disable అయ్యింది manually disable చేసినప్పుడు validation నుంచి exclude అవుతుంది
    enabled field active లో ఉంది default state normal usage
    errors error details ఉంటాయి validation fail అయితే ఏ error వచ్చిందో చూపడానికి
    status మొత్తం state (VALID, INVALID, etc.) ఎప్పుడూ ఉంటుంది debugging / advanced logic కోసం
    Angular Form States (Pristine vs Dirty + markAs Methods)

    🔹 Basic Idea

    • pristine → మార్పు లేదు (unchanged)
    • dirty → మార్పు జరిగింది (changed)

    👉 ఇవి రెండూ ఒకదానికి opposite

    🔄 State ఎలా change అవుతుంది?

    🟢 Initial State (Form load అయిన వెంటనే)

    pristine = true
dirty = false
    👉 ఎందుకంటే user ఇంకా ఏమీ చేయలేదు

    🟡 User value మార్చినప్పుడు

    ""  →  "Ram"
pristine = false
dirty = true
    👉 ఒకసారి change జరిగిన వెంటనే dirty అవుతుంది

    ⚠️ Important Point

    ❓ User మళ్లీ original value కి తీసుకెళ్తే? 

    "Ram" → ""
    👉 అయినా కూడా: 
    dirty = true   // మారదు ❗
pristine = false

    👉 ఎందుకు?
    ఒకసారి అయినా change జరిగింది

    🔧 Angular ఎలా చూస్తుంది?

    👉 Angular ఇలా ఆలోచిస్తుంది:
    “User ఈ field‌ని edit చేశాడా లేదా?”

    • ✔️ edit చేశాడు → dirty
    • ❌ edit చేయలేదు → pristine

    👉 ఇది current value కాదు, user action history మీద ఆధారపడుతుంది

    💡 Real Use Case

    ❌ Wrong way (bad UX) 

    <div *ngIf="control.invalid">
  Error
</div>

    👉 page load అయ్యగానే error కనిపిస్తుంది 😒

    ✅ Correct way 

    <div *ngIf="control.invalid && control.dirty">
  Error
</div>

    👉 User change చేసిన తర్వాతే error చూపిస్తుంది 👍

    🔁 Reset చేస్తే ఏమవుతుంది?

    control.reset();
    👉 మళ్లీ: 
    pristine = true
dirty = false
    👉 పూర్తిగా initial state కి వెళ్తుంది

    🧠 Easy గుర్తుపెట్టుకోవడానికి

    • pristine = clean slate 🧼
    • dirty = edited ✏️

    🔧 Manual State Methods

    👉 ఇవి manually state మార్చడానికి ఉపయోగిస్తారు

    🔸 markAsPristine()

    control.markAsPristine();
    - pristine = true
    - dirty = false
    💡 Use: form save/reset తర్వాత

    🔸 markAsDirty()

    control.markAsDirty();
    - dirty = true
    - pristine = false
    💡 Use: programmatically change చేసినప్పుడు

    🔸 markAsUntouched()

    control.markAsUntouched();
    - touched = false
    - untouched = true
    💡 Use: error messages hide చేయడానికి

    🔄 Comparison Table

    Method ఏమి చేస్తుంది Result
    markAsPristine() dirty → pristine change remove చేసినట్టు
    markAsDirty() pristine → dirty change force చేసినట్టు
    markAsUntouched() touched → untouched user interaction remove చేసినట్టు

    🔥 Real-life Example

    this.form.reset();

// or manually
this.name.markAsPristine();
this.name.markAsUntouched();

    👉 Result: - errors hide అవుతాయి
    - form fresh గా కనిపిస్తుంది

    ⭐ Most Commonly Used

    🔸 markAllAsTouched()

    this.form.markAllAsTouched();
    👉 submit సమయంలో అన్ని errors చూపించడానికి

    ⚖️ Usage Priority

    Method Usage Level
    markAsTouched() ⭐⭐⭐ Very High
    markAsPristine() ⭐⭐ Medium
    markAsUntouched() ⭐⭐ Medium
    markAsDirty() ⭐ Rare

    🔥 Real-world Flow

    if (this.form.invalid) {
  this.form.markAllAsTouched();
  return;
}

    👉 ఇది productionలో most common pattern 🚀
